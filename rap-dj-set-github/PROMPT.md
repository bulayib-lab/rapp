Прочитай CLAUDE.md и index.html. Сайт RAP DJ SET уже имеет базовую анимацию (hero с диджейской установкой, View Transitions, схема перехода, визуализатор файлов, наклон постеров). Твоя задача — поднять его на следующий уровень: сделать ощущение дорогого живого продукта в стиле клубной/underground рэп-культуры. Дизайн взрослый, тёмный, без детскости.

Порядок работы:
1. Запусти сайт (`python3 -m http.server 3000`), сделай скриншоты главной и каждой вкладки на 375, 768 и 1440 px через Playwright. Кратко опиши, что выглядит слабо, что лагает, какие анимации сделаны грубо.
2. Предложи план из 6–8 шагов и сразу делай шаг за шагом. После каждого шага проверяй скриншотами и консолью, потом `git commit`.

Что хочу получить (приоритет сверху вниз):
1. Единая система движения: CSS-переменные для easing, длительностей и задержек, один набор правил для появления блоков. Убери дублирование анимаций.
2. Hero главной: сделай установку богаче (вертушки с бликами, подсветка кнопок и эквалайзера, реакция на наведение и касание). Добавь режим «Play» с красивой анимацией, в котором эквалайзер и платтеры реагируют на ритм (синтезированный метроном на Web Audio, по умолчанию звук выключен).
3. Scroll-driven анимации: заголовки разделов, плитки артистов и карточки выезжают по скроллу (CSS `animation-timeline: view()` там, где поддерживается, иначе IntersectionObserver). Сборку микрофона в углу улучши: тоньше линии, плавнее появление деталей, без подписи и без пружин.
4. Анализ перехода: сделай схему на таймлайне интерактивной. Пользователь двигает точку входа второго трека, а кривые громкости и EQ пересчитываются; показывай подсказки «сейчас бас A вниз», «сейчас включи B».
5. Мои файлы: добавь два трека на деки A/B с общим кроссфейдером, который реально микширует их через Web Audio (громкость и три полосы EQ на канал). Визуализатор должен быть красивее: плавный спектр, пики, подпись времени.
6. Постеры артистов: добавь параллакс слоёв внутри постера и аккуратный блик при наведении (только устройства с мышью). Не используй чужие фото и обложки, только оригинальную графику.
7. Скелетоны и пустые состояния: везде, где контент появляется не сразу, показывай аккуратные заглушки. Для пустого сета, пустого поиска и пустых «Мои файлы» нарисуй небольшие line-art иллюстрации в стиле hero.
8. Производительность: проверь Lighthouse (Performance и Accessibility, цель 90+), убери лишние перерисовки, разнеси CSS и JS по папкам `css/` и `js/` без сборщика, обнови `sw.js`, чтобы офлайн продолжал работать.

Ограничения:
