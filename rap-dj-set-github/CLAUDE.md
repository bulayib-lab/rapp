# RAP DJ SET — контекст проекта

Статический PWA-сайт-помощник для диджеев хип-хопа и трэпа. Разметка в `index.html`, стили в `css/app.css` (вид) и `css/motion.css` (вся анимация), скрипты в `js/data.js` (каталог, уроки, словарь EN), `js/motion.js` (hero и режим Play, живая схема перехода, появление блоков, пустые состояния, микшер A/B, визуализаторы) и `js/app.js` (состояние, вкладки, render). Порядок подключения: data → motion → app. Рядом `manifest.json`, `sw.js`, `icons/`. Деплой: Replit Static (publicDir = корень). Локально: `python3 -m http.server 3000`.

## Как устроен код
- Состояние: объект `ST` (вкладка, артист, сет, язык, `busy`, `res` …). Вкладки: массив `TABS`; каждая вкладка — функция в объекте `V`; всё рисует `render()`. Переход между вкладками — `go(tab)` (использует View Transitions API, если он есть).
- Данные: `ART` (85 артистов, 829 названий треков), `VIBE` (цвета и советы основных артистов), `T` (7 видов переходов), `TC` (кривые громкости и баса для схемы перехода), `LES` (уроки), `TIPS`, `FX`/`FXM` (SVG-заставки при смене вкладки).
- Система движения: токены `--e-out/--e-in/--e-io` и `--d-xs…--d-xl` в `css/motion.css`. Появление блоков одно: `observe()` вешает `.rv` на h2/карточки/плитки; видимые сразу получают `.in` со стаггером, ниже экрана — `.sd` (CSS `animation-timeline: view()`) или IntersectionObserver. Заставку `#fx` при смене вкладки убрали по просьбе владельца — не возвращать.
- Анимации: hero с диджейской установкой (`.rig`, параллакс от курсора), слова заголовка (`.split`), схема перехода `tline()`, кольцо совместимости `ring()`, скелетон `skel()` на время «анализа» в `find()`, счётчик `cu()`, 3D-наклон постеров и подсветка карточек (один обработчик `pointermove`), полоса прокрутки `#prog`, сборка микрофона `#build` (`buildUpd()`).
- «Мои файлы»: пользователь загружает свои аудио; `detectBPM()` считает BPM, плеер на canvas (`vzDraw()`, `libPlay()`), спектр через Web Audio `AnalyserNode`. Файлы остаются в браузере.
- Язык RU/EN: русский текст в коде, английский — в словаре `EN` (пары «русская фраза → английская») через `L()`. Каждая новая русская строка ОБЯЗАНА получить английскую пару.
- BPM и тональности у каталога — demo (`info()` считает из названия трека). Никогда не называй их реальными.
- Хранение: `localStorage` через `db` (в try/catch).

## Дизайн-скилл
В `.claude/skills/ui-ux-pro-max` лежит скилл с базой стилей, палитр и UX-правил. Перед дизайн-задачами запускай его поиск, например `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "dj nightlife hip-hop" --design-system`.

## Правила
- Никаких защищённых авторским правом фото, обложек, аудио и ссылок на пиратскую музыку. Картинки артистов только оригинальные стилизованные.
- Реальной оплаты нет; лимиты FREE/PRO — только заготовка (`PLANS`).
- Стиль: тёмный, дорогой, взрослый. Без «пружинящих» анимаций, смайликов-иконок и мультяшности.
- Анимировать только `transform` и `opacity`. Уважать `prefers-reduced-motion` (при нём контент должен оставаться видимым), держать 60 fps на телефоне, не ломать мобильную версию (375 px), клавиатуру и фокус.
- Новые пары EN добавляй длинными и конкретными: `L()` заменяет подстроки, короткий ключ вроде «такт » ломает чужие фразы. Динамический текст (подсказки схемы) собирай на нужном языке в коде.
- После любых правок: проверить все вкладки в RU и EN, консоль без ошибок, обновить версию кэша в `sw.js` (и список файлов в нём).

## Проверка
Playwright уже есть в окружении. Браузер: `/opt/pw-browsers/chromium-*/chrome-linux/chrome` (`executablePath`, флаг `--no-sandbox`). Шрифты Google в песочнице могут не грузиться — это не ошибка сайта.
